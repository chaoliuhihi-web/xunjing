## 设计目标

本组设计图把两类已验证机制落入寻境自己的产品语言：

- 从 Polarsteps 借鉴地图、时刻、媒体和故事同步的完整旅程回放，但不复制品牌与页面，不把估算线路画成精确道路。
- 从 Journi 借鉴拍摄时间与可靠位置驱动的自动分组、地图章节、完整书稿和受控换版，但不做模板市场和逐页重排。

## 使用边界

- 图片是高保真产品设计稿，不是已开发、已上线或真实用户验证证据。
- 图中的照片、地点和数据只用于说明页面层级；开发与验收必须换成真实用户授权素材和真实接口数据。
- 开发不得从位图硬编码文字或数值，应依据配套功能文档实现状态、降级、隐私和异常链路。
- 正式地图需使用合规底图、地图来源与审图号；精确位置和敏感地点遵守产品文档的默认模糊规则。
