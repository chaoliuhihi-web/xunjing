## 1. 设计结论

寻境应吸收两类已经被海外产品验证、且与本产品主链路高度一致的机制：

1. Polarsteps 的价值不只是“地图上有一条线”，而是把地图、日期、时刻、照片、故事、交通和旅程总结同步成一段可以完整回看的旅行。
2. Journi 的价值不只是“照片自动排版”，而是用照片原始拍摄时间和可靠位置先整理时间线与地点组，再自动生成地图、章节和整本首版，用户只处理少量例外。

寻境采用机制，不复制竞品品牌、图标、文案、页面资产或视觉识别。寻境还必须比竞品营销表达更严格：估算距离不是精确道路，照片地点顺序不是连续轨迹，位置缺失时不为了好看补经纬度。

## 2. 完整旅程回放

### 2.1 用户承诺

> 不用重新剪视频，也能从头到尾看一遍我们真正走过的旅行。

回放对象是“实际旅程”，不是计划预演。行前计划继续使用“我们的旅行计划”标识；行后回放使用“实际旅程 / 真实回忆”标识，两者不能混用。

### 2.2 入口与页面层级

入口优先级：

1. 行后生成完成页主卡片：`查看旅程回放`。
2. 单趟旅程详情：`回放`页签。
3. 作品库的回忆电影详情：`查看完整旅程`。
4. 旅行书的路线总览页：`在地图中回看`，仅数字版提供。

页面由四层构成：

| 层级 | 必须显示 | 主要交互 |
| --- | --- | --- |
| 顶部上下文 | 标题、实际旅程标识、日期/天数 | 切换日期，返回整趟概览 |
| 地图舞台 | 当前位置、时刻标记、照片缩略标记、证据路线、地图来源 | 点标记跳到时刻，拖动/缩放，重置镜头 |
| 当前时刻卡 | 时间、地点/区域、交通方式、照片/视频数量、一句摘要、贡献者 | 展开照片和故事，纠正地点，隐藏敏感内容 |
| 播放控制 | 播放/暂停、前后时刻、进度条、0.5×/1×/2×、静音 | 拖动到日期/时刻，继续自动播放 |

### 2.3 回放叙事顺序

```text
整趟概览 2–4 秒
  -> 第一天标题 1–2 秒
  -> 时刻 1：地图聚焦 + 路段推进 + 照片/短视频 + 一句摘要
  -> 时刻 2…
  -> 下一天标题
  -> 最后一个时刻
  -> 旅程总结：天数、主要地点、照片数、同行人
  -> 分享回忆电影 / 继续翻阅旅行书
```

- 默认自动回放控制在 30–60 秒；完整内容不删除，用户可按日继续看。
- 地图镜头移动、路线进度、当前时刻卡和媒体切换必须同一时钟驱动，禁止各自定时导致错位。
- 用户拖动时间轴后立即暂停，地图和卡片定位到最近完整时刻；再次点击播放才继续。
- 点选某张地图照片时，暂停并展开对应照片簇；关闭后回到原时刻，不从头播放。
- 切换日期时保留当前缩放偏好；返回整趟概览时恢复适合全程的镜头。

### 2.4 路线证据视觉规则

| 用户看到的标签 | 证据 | 视觉 | 交互说明 |
| --- | --- | --- | --- |
| 轨迹记录 | 轻量记录或完整足迹中通过清洗的连续点 | 青绿色实线 | “设备记录到的轨迹片段” |
| 照片位置 | 两个及以上可靠照片地点组及时间顺序 | 珊瑚色点线 | “根据照片时间与位置还原的到访顺序” |
| 交通衔接 | 订单、计划或用户确认的飞机/火车/汽车转场 | 灰色虚线 + 交通图标 | “交通转场示意，不代表实际道路” |
| 地点未确定 | 只有时间或视觉弱线索 | 不连线，可显示日期卡 | “位置证据不足，未显示路线” |

共同规则：

- 实线、点线、虚线和断点在实际旅程、回忆电影、分享页和旅行书保持一致。
- 不显示原始经纬度数值；普通用户只需理解证据类型。
- 路线来源说明可点开，但不展示内部置信分数、模型名或坐标系字段。
- 敏感地点在私密回放中默认模糊到区域；公开分享再次降精度。
- 地图加载失败时回退为按日的时刻时间线和媒体回放，不阻断完整旅程回顾。

### 2.5 低操作纠错

只有三类纠错入口：

1. `纠正地点`：打开当前照片组的区域地图，整组移动，不逐张改坐标。
2. `不是这段交通`：在候选交通方式中改一次，整段生效。
3. `从作品中隐藏`：隐藏地点、照片组或人物；不删除原素材。

纠错后只重算受影响日期、回忆电影和书中地图，不要求用户重新生成整趟旅行。

### 2.6 P0 验收

- 100 张以上真实照片、无轨迹样本仍能形成按日/时刻回放。
- 有轨迹和无轨迹样本的线型明显不同；断点不会被补成实线。
- 播放、暂停、拖动、按日跳转、点击地图标记、展开照片和返回均保持上下文一致。
- 当前时刻变更后 300 毫秒内完成地图高亮与卡片切换；地图动画可更长，但内容不能错位。
- 回放结束可进入回忆电影分享和旅行书翻阅；任一生成失败时显示单独重试，不阻断另一个作品。
- 位置权限拒绝、地图离线、素材缺失、某一天无位置和敏感地点均有可理解的降级页面。

## 3. 自动成书：时间、位置与地图

### 3.1 经纬度真正起什么作用

Journi 值得采用的不是向用户展示经纬度，而是把照片的“何时拍、在哪里拍”变成自动成书的结构输入：

1. 拍摄时间决定基础顺序和日期边界。
2. 可靠位置帮助把相邻照片分成地点组，辅助章节和地图。
3. 时间与位置组合识别转场、同地停留和不可能的短时跨城跳变。
4. 地点组数量与可靠程度决定生成路线总览、章节地图、地点卡还是省略地图。
5. 用户修改一组照片的地点后，时间线、地图和章节统一更新，不逐页人工修复。

位置不是成书前提。无 GPS 时继续用时间、计划、同行素材、视觉内容和少量整组确认形成书；证据仍不足就省略精确地图。

### 3.2 素材入口规则

- 首选系统相册原始资产；在任何压缩、裁切、转码或上传前读取拍摄时间、时区、GPS、方向和原始尺寸。
- 文件创建时间、修改时间、缓存时间和上传时间不作为拍摄时间。
- 微信/聊天软件转发图、截图、社交平台保存图和编辑副本单独标识；允许成书，但不承诺自动地图。
- 原始照片只读；时间校正、色彩优化、裁切和版式都写入派生资产与书稿版本。
- 单次选择后后台处理，用户无需再按“预览图/原图”二次上传。

### 3.3 地图生成决策

```text
是否存在可靠地点组？
  ├─ 否 -> 不生成精确地图，按时间/人物/事件成章
  └─ 是
      ├─ 只有 1 组 -> 地点卡或区域小图，不连路线
      └─ 至少 2 组
          ├─ 顺序可信 -> 生成地图章节，按证据类型画线
          └─ 顺序冲突 -> 提 1 个整组问题；未确认前只显示地点点位
```

- 全书路线总览优先出现在封面后或序言后。
- 章节地图可作为整页/跨页分隔，进入新城市、新区域或长交通转场时使用。
- 只有照片位置时，端点可显示照片或地点，连接使用点线；不得贴道路生成实轨。
- 酒店、住址、医院、儿童活动地点等默认模糊或不进入公开/印刷地图。
- 地图来源、审图号、坐标转换和原始证据检查由系统自动完成；不把合规责任交给用户。

## 4. 自动成书：排版与整本节奏

### 4.1 先给完整书，不先给模板

用户第一次进入书稿时直接看到：

- 可真实翻页的完整首版。
- 页数、章节数、地图页数和需确认问题数。
- “整本节奏”缩略总览。
- 一个主动作：`继续翻阅`；有问题时提供次动作：`查看问题`。

不得把模板商城、尺寸选择或空白画布作为首屏。商品规格只保留当前标准书型；用户确认首版后再看价格、装帧和付款。

### 4.2 页型库

| 页型 | 使用条件 | 版面约束 |
| --- | --- | --- |
| 封面 | 每本 1 个 | 一张主图或克制拼贴，标题可读 |
| 路线总览 | 至少 2 个可靠地点组 | 1 个整页/跨页，真实证据线型 |
| 章节开场 | 新日期、城市或叙事阶段 | 日期/地点只出现一次，1 张主图 |
| 主图跨页 | 高质量横图或视觉高潮 | 主体避开书脊，允许短标题 |
| 双图/三图叙事 | 同一事件的互补照片 | 保持时间或动作关系 |
| 拼贴 | 多个次要但有意义的细节 | 叙事页默认不超过 6 张 |
| 连续镜头 | 同一动作或短时间序列 | 按时间顺序，不混入无关照片 |
| 安静文字 | 有真实故事、票根或语音内容 | 保持留白，不用 AI 凑长文 |
| 地图分隔 | 新区域或长转场 | 可整页，不展示不可信地点 |
| 结尾 | 每本 1 个 | 返回全程、人物或一句真实收束 |

排版节奏规则：

- 同一页型默认不连续超过 2 个跨页。
- 章节开场后 2–4 个跨页内出现一次视觉高潮；高潮后安排低密度页面缓冲。
- 竖图、横图、全景、夜景、合影和连续镜头使用不同适配页型，不通过过度裁切强塞同一模板。
- 自动版式最多给 3 个通过印刷安全检查的候选；“换一个版式”只替换当前跨页或当前章节，不重新洗牌整本书。
- 日期标题默认每个日期/章节出现一次，不在每页重复。
- 自动曝光和色彩只作用于派生图并可关闭；纪实内容不做生成式改写。

### 4.3 整本节奏总览

总览不是编辑器画布，而是用户理解整本作品的导航：

- 缩略图展示页型、章节边界、地图页和当前页。
- 页型变化、连续重复和异常页用轻提示表示。
- 点缩略图直接跳到对应跨页；长按不进入自由拖拽模式。
- 只有系统判断为高影响问题的页面显示“需确认”。
- 用户可从总览批量隐藏一个照片簇或章节，但删除前预览受影响页数。

### 4.4 只确认关键问题

问题按整组、整段或整页出现，每趟旅行总计不超过 3 个：

- 地点组：“这组 32 张照片可能拍摄于什刹海”。动作：`正确 / 在地图上修改 / 暂不确定`。
- 人物：“封面人物是否为主要同行人”。动作：`是 / 换一张 / 隐藏姓名`。
- 印刷风险：“这张主图分辨率偏低”。动作：`换推荐图 / 仍然使用 / 隐藏`。

定位问题同时显示用户可理解的证据来源和地图使用结果，例如“原始照片位置”“轨迹匹配”“行程推断”“可生成地图章节”“只显示地点卡”。不展示生硬置信分数。

## 6. 前端组件与埋点建议

建议组件边界：

- `TripReplayPlayer`：回放时钟、播放控制和日/时刻跳转。
- `EvidenceRouteLayer`：实线、点线、虚线、断点和来源说明。
- `TripMomentSheet`：当前时刻卡、素材簇与纠错。
- `BookRhythmOverview`：页型总览、章节边界与跳页。
- `MapUsageReviewCard`：地点组问题、证据说明和地图用途。
- `SafeLayoutSwitcher`：当前跨页 2–3 个安全候选。

最小埋点：

- `trip_replay_open / start / pause / seek / day_jump / moment_open / complete`
- `trip_replay_share_movie / open_book`
- `location_group_review_open / confirm / map_edit / defer`
- `book_overview_open / page_jump / issue_open`
- `book_layout_switch / accept`

埋点不得包含精确经纬度、原始照片 URL、酒店、家庭住址、儿童姓名或书稿正文。

## 7. P0 与后续边界

P0：2D 完整回放、按日/时刻控制、证据路线、地图与时刻联动、完整首版、整本节奏、证据驱动地图页、最多 3 个安全候选版式、最多 3 个高影响问题。

P1：数据充分时的 3D 飞越、海拔/交通统计、GPX、延迟分享、第二书型、多趟年鉴。

当前不做：公开旅行社区、默认持续定位、运动级精度承诺、专业视频时间轴、空白画布、无限模板市场、逐张经纬度编辑和无证据路线补全。
