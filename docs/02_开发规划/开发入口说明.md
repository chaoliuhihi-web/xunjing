## 当前范围

围绕同一个 `Trip` 完成六个闭环：

1. 行前攻略导入、路线核对和动态预演。
2. 行中今日行程、导航调起和轻记录。
3. 行后照片识别与实际旅程重建。
4. 旅行故事、足迹卡和回忆电影。
5. 旅行书完整首版、翻页、轻修改、一次付款与履约。
6. 作品库与基础个人旅行档案。

合作方、加盟、渠道分润和结算暂不实施。地图内容商店、图书/地图/地球仪扫码、公益报告和 B/G 平台继续保留，但不进入当前 C 端任务。

## 正式代码落点

```text
assets/references/APP/kashgar-mini-program/ # C 端 UniApp/H5/小程序
backend/yudao/yudao-module-xunjing/         # C 端与运营后台业务
backend/yudao/sql/mysql/                    # SQL 和迁移
services/memory-book-worker/                # Codex Harness、travel-memory-book Skill、成书与媒体制品
ops/                                        # 环境和部署
scripts/                                    # 验收门禁
qa/xunjing-c-product/                       # 任务证据
```

不得新建 `services/api`、第二套前端、第二个 Worker 或单独数据库来绕开现有基座。

成书后台不另建通用 Agent 平台：在现有 `services/memory-book-worker/` 内以服务器 Codex SDK/App Server 作为 Harness，并安装锁定的 `travel-memory-book` Skill。任务继续由 Yudao 建立和持久，Harness 只返回受约束的生成制品。

## 开工方式

```bash
git status --short
git branch --show-current
git remote -v
git fetch github main
git fetch origin main
git rev-list --left-right --count HEAD...github/main
git rev-list --left-right --count HEAD...origin/main
```

当前工作树很脏时，使用 clean worktree 或只暂存任务文件；不得重置用户改动。任务分支使用 `codex/<task-id>-<slug>`。

从 AI 任务书 `XJ-C0-01` 开始，不得跳过基线审计直接并行堆功能。
